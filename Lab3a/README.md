
## Instructions

* For all the other components **manual test cases** have been written to test the components throughly, incorporating all the possible cases.


## Scripts
* **Counter.py**
   
   ```
   python3 Counter.py <start1> <count_up> <start2> <count_down>
   ```
   Generates a test case that loads "start1" and then counts up for "count_up" number of times. Then loads "start2" and counts down "count_down" number of time.
