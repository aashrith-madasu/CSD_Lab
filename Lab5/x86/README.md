# Instructions to run

1. To run all the steps:
```
make all
```

2. To run specific step:
```
make <step>
```

### **Steps available:**

* **pp** - preprocess to .i files.
* **compile** - compile to .s (assembly) files.
* **asm** - assemble the .s files to get the .o (object) files.
* **link** - to link all the object files to get .out (executable) file
* **dump** - to get the object file contents and symbol tables for every object file.
